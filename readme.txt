Understand recurring product return reasons and review evidence that can guide corrective changes. This early test build provides structured reason capture and basic reporting; it does not process return requests.

== Description ==

WPEssential Return Insights & Prevention for WooCommerce helps store teams collect item-level return reasons, review patterns, and decide what product details or processes may need attention.

This build is for private testing. It is not a WordPress.org or WooCommerce.com release. Do not use it as a production return-management system.

== Installation ==

1. Upload the ZIP through Plugins > Add New Plugin > Upload Plugin.
2. Install and activate WooCommerce first.
3. Activate WPEssential Return Insights & Prevention for WooCommerce.
4. Open the plugin from the WooCommerce admin menu.
